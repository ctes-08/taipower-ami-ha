# Brand assets

The icon in this directory is original, neutral artwork for the unofficial
Taipower AMI Home Assistant integration. It represents a generic smart meter
and energy history; it does not reproduce or imply endorsement by Taiwan Power
Company, Home Assistant, or another utility.

The source artwork was generated with OpenAI image generation on 2026-08-30,
then cropped and resized losslessly for Home Assistant:

- `icon.png`: 256 x 256 pixels
- `icon@2x.png`: 512 x 512 pixels
